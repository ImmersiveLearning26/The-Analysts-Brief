# Image prompts: realistic props for the dialogue films

Realistic photo objects (no paper-cut look) for the two films that play in the dialogue cards: Dr Diallo (P02) and Hon. Mwangi (P09).
Save each image under the file name shown, in `Analysts_Brief_Claude_Kit/films/props_raw/`. I key out the green, trim and animate them.

**Settings for every image**
- Model: Nano Banana Pro (Gemini 3 Pro Image); GPT-Image-2 or Kling Image 4.0 also work.
- Aspect ratio **1:1**, resolution **2K**, one image per prompt.
- Run it again if it has readable text, a green tint or a shadow on the background, or more than one object.

**Drawn in code, not generated:** the Kalinda map, roads, river and borders, the DISPUTED stamp, vote tallies, clash marks, rumour lines, money and contract arrows, all words and numbers, and the fold into the case file. These will be clean flat graphics, not paper.
